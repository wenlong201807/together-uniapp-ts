# 首页重构设计方案

## 一、现状分析

### 当前首页实现 (`/src/pages/tabbar/home.vue`)

**现有功能：**
- 欢迎区域：显示用户昵称和简单问候语
- 3个快速入口：发布动态、查看推荐、我的关注
- 最新动态列表：简单的帖子流展示

**存在问题：**
1. **缺乏个性化推荐**：所有用户看到相同内容，无差异化
2. **信息密度低**：页面利用率不足，缺少丰富的业务模块
3. **用户粘性弱**：无热门内容、无附近的人、无话题引导
4. **视觉单调**：UI设计简单，缺乏吸引力和现代感
5. **无推荐算法**：未利用用户画像、行为数据进行智能推荐

---

## 二、产品设计方案

### 2.1 整体架构

首页采用**多模块混合推荐流**设计，包含以下核心业务模块：

```
┌─────────────────────────────────────┐
│  1. 顶部导航栏 (Top Navigation)      │
├─────────────────────────────────────┤
│  2. Banner轮播 (Banner Carousel)     │
├─────────────────────────────────────┤
│  3. 快速入口 (Quick Actions)         │
├─────────────────────────────────────┤
│  4. 智能推荐流 (Smart Feed)          │
│     - 个性化推荐卡片                 │
│     - 热门内容卡片                   │
│     - 附近的人卡片                   │
│     - 话题模块卡片                   │
│     - 新用户推荐卡片                 │
├─────────────────────────────────────┤
│  5. 话题模块 (Topic Modules)         │
├─────────────────────────────────────┤
│  6. 无限滚动 (Infinite Scroll)       │
└─────────────────────────────────────┘
```

### 2.2 核心业务模块详细设计

#### **模块1：顶部导航栏**

**功能：**
- 左侧：Logo + 城市定位（可点击切换城市）
- 中间：搜索框（支持搜索用户、话题、动态）
- 右侧：消息通知图标（红点提示）

**交互：**
- 点击城市：弹出城市选择器，支持定位和手动选择
- 点击搜索：跳转到搜索页面
- 点击消息：跳转到消息列表

---

#### **模块2：Banner轮播**

**功能：**
- 展示运营活动、热门话题、推荐用户
- 支持3-5张轮播图
- 自动播放 + 手动滑动

**数据来源：**
- 后端配置的运营Banner
- 热门话题自动生成Banner
- 高质量用户推荐Banner

**交互：**
- 点击Banner：跳转到对应详情页（活动页、话题页、用户主页）

---

#### **模块3：快速入口**

**功能：**
- 4-6个快速入口图标
- 常见入口：发布动态、查看推荐、附近的人、话题广场、活动中心、VIP特权

**设计：**
- 图标 + 文字标签
- 支持横向滚动（超过4个时）
- 图标采用渐变色设计，增强视觉吸引力

---

#### **模块4：智能推荐流（核心）**

这是首页的**核心模块**，采用**混合推荐策略**，包含以下5种推荐类型：

##### **4.1 个性化推荐卡片**

**推荐算法：协同过滤 + 内容推荐**

**协同过滤（Collaborative Filtering）：**
- 基于用户行为相似度推荐
- 计算公式：
  ```
  相似度(用户A, 用户B) = cosine_similarity(行为向量A, 行为向量B)
  
  行为向量 = [浏览权重, 点赞权重, 评论权重, 收藏权重, 关注权重]
  权重设置：浏览=1, 点赞=3, 评论=5, 收藏=4, 关注=6
  ```

**内容推荐（Content-Based Filtering）：**
- 基于用户兴趣标签匹配
- 计算公式：
  ```
  匹配度 = Σ(用户兴趣标签权重 × 内容标签权重) / 标签总数
  
  兴趣标签权重：用户设置的兴趣等级（1-5星）
  内容标签权重：内容包含该标签的强度（1-5）
  ```

**卡片设计：**
- 用户头像 + 昵称 + 年龄 + 城市
- 个人简介（1-2行）
- 兴趣标签（最多3个）
- 照片墙（3张照片网格）
- 底部操作：喜欢、跳过、查看详情

---

##### **4.2 热门内容卡片**

**推荐算法：热度排序（Wilson Score + 时间衰减）**

**Wilson Score计算：**
```
Wilson Score = (p + z²/2n - z × sqrt(p(1-p)/n + z²/4n²)) / (1 + z²/n)

其中：
- p = 正向互动数 / 总互动数
- n = 总互动数
- z = 1.96（95%置信度）
- 正向互动 = 点赞 + 收藏 + 评论
- 总互动 = 正向互动 + 跳过 + 举报
```

**时间衰减：**
```
最终热度 = Wilson Score × e^(-λt)

其中：
- λ = 衰减系数（建议0.1）
- t = 发布时间距今的小时数
```

**卡片设计：**
- 标记"🔥 热门"标签
- 显示热度值（点赞数、评论数）
- 其他设计同个性化推荐卡片

---

##### **4.3 附近的人卡片**

**推荐算法：LBS地理位置推荐**

**距离计算（Haversine公式）：**
```
a = sin²(Δlat/2) + cos(lat1) × cos(lat2) × sin²(Δlon/2)
c = 2 × atan2(√a, √(1-a))
距离 = R × c

其中：
- R = 地球半径（6371 km）
- lat1, lon1 = 用户位置
- lat2, lon2 = 目标用户位置
```

**距离权重：**
```
权重 = 1 / (1 + 距离/10)

距离范围：
- 0-5km：权重 1.0-0.67
- 5-10km：权重 0.67-0.5
- 10-20km：权重 0.5-0.33
- >20km：不推荐
```

**卡片设计：**
- 标记"📍 附近"标签
- 显示距离（如"距离你 3.2km"）
- 其他设计同个性化推荐卡片

---

##### **4.4 话题模块卡片**

**推荐算法：话题热度 + 用户兴趣匹配**

**话题热度计算：**
```
话题热度 = 参与人数 × 0.3 + 帖子数 × 0.5 + 互动数 × 0.2
```

**用户兴趣匹配：**
```
匹配度 = Σ(话题标签 ∩ 用户兴趣标签) / 话题标签总数
```

**卡片设计：**
- 话题标题 + 话题描述
- 参与人数 + 帖子数
- 话题封面图（3张精选帖子图片）
- 底部操作：参与话题、查看详情

---

##### **4.5 新用户推荐卡片**

**推荐算法：新用户冷启动**

**新用户定义：**
- 注册时间 < 7天
- 发布动态数 < 3条
- 互动数 < 10次

**推荐策略：**
```
推荐分数 = 资料完整度 × 0.4 + 照片质量 × 0.3 + 活跃度 × 0.3

其中：
- 资料完整度 = 已填写字段数 / 总字段数
- 照片质量 = 照片数量 / 20（最多20张）
- 活跃度 = 最近7天登录次数 / 7
```

**卡片设计：**
- 标记"🌟 新人"标签
- 显示注册天数（如"刚加入3天"）
- 其他设计同个性化推荐卡片

---

### 2.3 混合推荐策略

**推荐流组成比例：**
```
推荐流 = 40% 个性化推荐 + 20% 热门内容 + 15% 附近的人 + 15% 话题模块 + 10% 新用户推荐
```

**推荐流生成逻辑：**
1. 每次加载20条内容
2. 按比例分配：8条个性化 + 4条热门 + 3条附近 + 3条话题 + 2条新用户
3. 随机打乱顺序，避免模式化
4. 去重：已推荐过的内容不再推荐（24小时内）
5. 兜底策略：某类推荐不足时，用其他类型补充

**推荐流更新策略：**
- 下拉刷新：重新生成推荐流
- 上拉加载：追加新的推荐内容
- 定时刷新：每5分钟自动刷新一次（后台静默）

### 3.3 性能优化

#### **虚拟滚动**
- 使用 `uni-recycle-view` 实现虚拟滚动
- 只渲染可视区域的卡片，减少DOM节点

#### **图片懒加载**
- 使用 `uni-image` 的 `lazy-load` 属性
- 占位图 → 模糊图 → 高清图（渐进式加载）

#### **数据缓存**
- 推荐流缓存：本地缓存5分钟
- 用户信息缓存：本地缓存30分钟
- 话题列表缓存：本地缓存10分钟

#### **预加载**
- 滚动到倒数第3个卡片时，预加载下一页
- 预加载下一张Banner图片

#### **骨架屏**
- 首次加载显示骨架屏
- 避免白屏和闪烁

### 4.3 A/B测试

**测试维度：**
1. 推荐流比例：测试不同的推荐类型比例
2. 卡片样式：测试不同的卡片设计
3. 排序算法：测试不同的推荐算法

**测试方法：**
- 将用户随机分为A/B两组
- A组使用方案A，B组使用方案B
- 对比核心指标，选择最优方案

## 七、风险与应对

### 7.1 技术风险

**风险：推荐算法效果不佳**

## 八、总结

本方案通过**多模块混合推荐流**设计，结合**5种推荐算法**（协同过滤、内容推荐、热度排序、LBS地理位置、新用户冷启动），打造一个**个性化、智能化、视觉化**的首页。

**核心亮点：**
1. ✅ **智能推荐**：基于用户画像和行为数据的个性化推荐
2. ✅ **内容丰富**：热门、附近、话题、新用户等多种推荐类型
3. ✅ **视觉吸引**：现代化UI设计和流畅动画效果
4. ✅ **性能优化**：虚拟滚动、懒加载、缓存等优化手段
5. ✅ **数据驱动**：完善的埋点体系和A/B测试机制

**预期效果：**
- DAU提升30%
- 人均停留时长提升50%
- 推荐点击率达到15%
- 次日留存率达到60%
