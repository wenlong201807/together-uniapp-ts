# 红井革命旧址群讲解稿（原版）

## 总体讲解
尊敬的各位学员：
欢迎来到沙洲坝红井革命旧址群，这里就是毛主席亲自为群众开挖的一口水井——红井的所在地。位于瑞金市沙洲坝镇的沙洲坝村，面积600多亩，拥有革命旧址35处，其中，全国重点文物保护单位有8处。1933年4月中华苏维埃共和国临时中央政府从叶坪搬迁到沙洲坝，这里就成为苏维埃临时中央政府在瑞金的第二个驻地。一直到1934年7月，再从这里搬迁到云石山，中央政府一共在这里办公和居住了一年零四个月。在沙洲坝期间，尽管战争环境非常艰苦，以毛泽东为代表的中国共产党人仍然进行了一系列治国理政的伟大实践，使中央苏区发展到鼎盛时期。

在我们正前方的是一棵有700多年历史的古樟树，它远远看上去像是三棵树，其实是由一棵树发的三根枝，当地老百姓把这三根枝比喻为三大伟人，中间的是伟大领袖毛泽东，左边的是鞠躬尽瘁的周恩来，右边的是从枪林弹雨中走出来的朱德。这里同时也是瑞金的红色影视基地，许多电影、电视剧都有在这里取景拍摄，比如电视剧《长征》，它的1-5集都是在瑞金取景的，而这棵树也多次上镜。这棵树在1963年曾被国家邮政局整体拍下，同时以毛泽东旧居作背景，发行过一套面值3分、4分和5分的邮票，很有纪念价值。好的，各位学员，我们到毛泽东旧居里面看看，这边请，大家小心门槛。

## 毛主席旧居
这栋房子原是苏区时期地主杨衍兰的私祠，称为元太屋，建于1876年，是典型的客家民居。1933年4月，中央执行委员会从叶坪迁驻到这里，在这里居住和办公的有毛泽东、何叔衡、徐特立、谢觉哉，除毛泽东之外，其他三位与林伯渠、董必武一起被人们尊称为"苏区五老"。徐特立是毛泽东的老师，何叔衡是毛泽东的挚友，谢觉哉是毛泽东的秘书，何叔衡和徐特立是莫斯科中山大学的同学，何叔衡和谢觉哉是湖南宁乡的老乡。所以四人的关系非常密切。四人人在这里办公和居住的时候，经常坐在一起开会和聊天，有一天，他们在讨论沙洲坝人民的生活和生产问题的时候，一致认为，沙洲坝有两个问题亟待解决，一是群众喝水没有水井，二是小孩读书没有学校。不久之后，毛主席带领乡亲挖了一口水井，徐特立发动群众办起了列宁小学。一口水井、一所小学，体现了党和政府践行群众路线的优良作风。接下来，我们到毛主席的办公室兼住室看看，这边请。

毛泽东在这里办公期间，把主要精力放在了苏维埃的政权建设上。他经常深入田间地头，了解群众生产和生活上的困难。这一时期也是毛泽东一生中开展调查研究和写调查报告最多的一个阶段。开展了才溪乡调查和长岗乡调查，还写下了《关心群众生活，注意工作方法》《我们的经济政策》《必须注意经济工作》等光辉著作，这些著作，后来被编入了《毛泽东选集》的第一卷。其中，《关心群众生活，注意工作方法》一书中，提出：真正的铜墙铁壁是什么？是群众，是千百万真心实意地拥护革命的群众，这是真正的铜墙铁壁，是什么力量也打不破的，完全打不破的。这和习近平总书记提出的"人民就是江山，江山就是人民"的人民政权思想是一致的。

苏区时期，物资匮乏，条件艰苦。中央政府规定，中央政府工作人员夜晚办公可点三根灯芯。而毛主席却以身作则，坚持艰苦朴素的工作作风和生活作风，每天晚上只点一根灯芯。在昏暗的油灯下，毛主席伏案在此写下了一系列光辉著作。直到今天，以习近平同志为代表的中共中央，始终坚持艰苦朴素的工作作风和生活作风，为党和人民树立了光辉的榜样。

这里是徐特立的办公室兼住室，徐特立是伟大的革命教育家，于1930年底进入瑞金，参加了一苏大会和二苏大会，当选为中央教育部副部长、代理部长。在他的领导下，苏区的教育事业发展得红红火火，为苏区的教育事业作出了重大贡献。大力开展"扫盲"运动，先后创办了列宁小学、列宁师范。当年在战火纷飞和物资极端匮乏的条件下，苏维埃政府普遍办起了列宁小学，师资不够，就创办师范培养师资；没有校舍，就把祠堂腾出来，当做教室；没有课桌，就用门板和砖头搭起台子当做课桌；还组织人员专门编写了"列宁小学课本"。经过艰苦努力，苏区大部分适龄儿童都得到了免费上学的机会。

1934年10月徐特立以57岁高龄参加了长征，他是当时长征队伍中年龄最大的一位同志。在他60岁寿辰的时候，毛主席为他举办了祝寿活动，并盛赞他是革命第一、工作第一、他人第一。并且专门给他写了一封信，信中写道：您是我二十年前的先生，现在仍然是我的先生，将来必定还是我的先生。对他给予了高度的评价。

这里是何叔衡的办公室兼住室。何叔衡是湖南宁乡人，1914年与毛泽东相识于湖南长沙，二人志同道合，成为挚友。何叔衡是党的一大代表，中国共产党的创始人之一。他于1931年进入瑞金，参加了一苏大会、二苏大会，在一苏大会后当选为工农检察部部长。在担任工农检查部长期间，恪尽职守，秉公办事，为苏维埃政权的廉政建设作出了卓越贡献。

1933年12月，中央执行委员会颁发了《关于惩治贪污浪费行为》第26号训令。明确规定：贪污公款500元以上者处以死刑，贪污公款300元以上500元以下者处以2至5年监禁，贪污公款100元以下处以强迫劳动半年。当时中央工农检察部就是严格按照这个训令开展了轰轰烈烈的反腐倡廉运动，建设了"真正的空前的廉洁的政府"。在这次反腐运动中，共查处贪污腐败案件200余起，被判处死刑的贪官共15名。其中，比较典型的案件有谢步升案。根据当时群众举报，检举叶坪村苏维埃政府主席谢步升的一系列贪污腐化行为。何叔衡接到举报后，立即成立了专案组调查此事。经过调查发现，谢步升利用职权贪污、偷盖公章、伪造通行证等一系列罪行，最终，谢步升被判处死刑，打响了苏区反腐第一枪。

1934年10月红军主力长征后，何叔衡奉命留在中央苏区坚持游击战争。1935年2月，从江西转移福建途中，在长汀突围战中为掩护同伴突围，壮烈牺牲，实现了他要"为苏维埃流尽最后一滴血"的铮铮誓言。

这里是谢觉哉的办公室兼住室。谢觉哉是湖南宁乡人，清末秀才。1933年来到瑞金，一度担任毛泽东的秘书，后担任中央政府秘书长。被誉为苏区红色管家。他是人民司法制度的奠基者之一，长期从事人民司法工作，1951年，他以南方老革命根据地慰问团团长的身份重新回到瑞金，带来了毛泽东的照片和毛泽东亲笔题字的"发扬革命传统，争取更大光荣"的锦旗。

好的，各位学员，接下来我们到隔壁的中央人民委员会旧址，这边请。中央人民委员会是中央执行委员会下设的最高行政机关，负责指挥全国政务，相当于我们现在的国务院。最早下设了九个部和一个局，后来随着革命战争的需要增设了国民经济人民委员部和粮食人民委员部，这些部局从叶坪迁到沙洲坝后，都分散在这附近办公。在这里面办公和居住的有张闻天、贺子珍以及一些工作人员。 室看看。

这里是贺子珍的办公室兼住室，贺子珍于1928年和毛泽东结婚，陪伴毛泽东度过了中国革命最为艰难曲折的阶段。在瑞金期间，贺子珍任中央政府机要科科长，管理重要机要文件。大家可能已经注意到，这个房间还摆放着一个摇篮，这是怎么回事呢？1932年贺子珍在福建长汀的福音医院为毛泽东生了一个男孩儿，毛泽东非常高兴，为他取名毛岸红，小名毛毛，这个摇篮就是毛毛的小床。1934年10月，中央红军主力长征时，毛毛留在了中央苏区由毛泽覃夫妇交给了一位农民抚养。解放后，贺怡（毛泽覃妻、贺子珍妹妹）急切的想到瑞金来寻找毛毛，不幸在吉安遭遇车祸去世，毛毛至今下落不明。

这里是张闻天的办公室兼住室，张闻天早期在苏联留学，是28个半布尔什维克之一。于1933年1月进入瑞金。在二苏大会上，他当选为中央人民委员会的主席。张闻天刚来的时候，由于受到王明"左倾"错误的影响，在思想上和毛泽东有不同的意见。然而，在这里居住期间，因为跟毛泽东住得比较近，经常交流探讨中国革命的重大问题，后来中央机关搬迁到云石山后又住在了一起，在这一时期，他的思想发生了很大的变化，由原来的脱离实际、教条主义转变为一个实事求是的真正马克思主义者。同时，逐渐赞同毛泽东的观点，与毛泽东同志的思想达成了一致，为遵义会议的召开起到了关键性作用。

他在当选为人民委员会主席以后，经常深入群众，解决群众的实际困难，比如当年的红色中华报这里就刊登了一个张闻天帮助红军家属砍柴的故事。

## 列宁小学
前面的这座小房子就是列宁小学。苏区时期，党和苏维埃政府十分重视教育工作，尤其是儿童教育工作，实施免费的义务教育。根据1934年1月统计，仅江西、福建、粤赣三省就有列宁小学3052所，学生近9万人，入学率达60%，而同一时期，白区号称教育最发达的江苏省入学率也只有10%。因此，毛泽东在二苏大会上这样评价苏区的教育，他说，谁要是跑来我们苏区看一看，那他就会看到一个自由光明的新天地。

（毛主席带领群众挖井雕像）这组雕塑是南京军区某集团军红一连，也是当年参与挖红井的部队，来到瑞金寻根问祖时捐献的，雕塑反映的是毛主席带领苏区军民挖井的情形。

前面这个书本形状的石碑上刻的就是红井的课本，这篇课文出自人教版语文课文一年级下册第二课，内容非常精炼，全文3段6句，去掉标点符号刚好是100字，很多人知道红井都是通过这篇课文知道的。

## 红井
在我们正前方的就是举世闻名的红井。接下来，我给大家简单介绍一下红井的由来。

当年的沙洲坝是个干旱缺水的地方，不仅无水灌田，就连群众喝水也非常困难。那时曾流传着这样一首民谣，民谣的大致意思是说：瑞金有个沙洲坝，三天无雨地开岔。老百姓喝脏塘水，没有水来洗手帕，有女儿的人家，不要把女儿嫁到沙洲坝"。说到这里，可能有人会问，沙洲坝人民为什么不挖井呢？原来，在这之前也有人想过去挖井，可是他们一来穷，二来迷信，听信风水先生说，沙洲坝地底下住着一条旱龙王，如果挖井动了龙脉，会惹怒龙王爷，十里八乡的百姓都要遭殃。所以没人敢带这个头打井。这里的人，祖祖辈辈喝水、洗衣、做饭用的都是同一口池塘里的脏塘水。

1933年4月，毛泽东搬迁到这里之后，发现这里的群众喝的是池塘里的脏水，便把解决群众饮水难的问题挂在心上，只要一有空，他就同警卫员商量着如何为群众挖井的事。

9月的一天早上，毛泽东带领着警卫员拿着锄头、铁锹来到池塘边准备挖井，这时一大早起来的老表发现了毛主席要挖井，充满了疑惑，毛泽东看到了挂在老乡脸上复杂的表情，于是笑着对大伙说：我知道你们迷信风水，怕得罪旱龙王，可我不怕，如果旱龙王要怪罪，就让他来找我好了。毛泽东的一席话，打消了村民的顾虑，大家纷纷加入到挖井的队伍中。在主席的带领下，没几天，一口直径1.2米，深约6米的水井就挖好了。为了使井水更清澈，毛主席又亲自下井底铺沙石、垫木炭。从此，沙洲坝人民结束了饮用脏塘水的历史，喝上了清澈甘甜的井水。

1934年10月中央红军长征离开瑞金后，国民党反动派又卷土重来，为了阻止人民群众对党、对毛主席和红军的思念，国民党反动派多次填掉这口井，当地群众就同敌人展开了针锋相对的斗争。敌人白天填井，群众夜晚又把井挖开，就这样填了又挖，挖了又填，反复好几次，沙洲坝人民终于取得了胜利。把水井留了下来。

1951年，沙洲坝人民为了迎接南方老革命根据地慰问团的到来，将这口井进行了全面整修，并把这口井取名为"红井"，同时在井旁立了一块木牌，刻上"吃水不忘挖井人，时刻想念毛主席"。后来，又将木牌改成了石碑。
